# Project overview

## Objective

Develop a second matching ground FlatSat testbed alongside the existing SJSU student testbed. A shared, controlled configuration is intended to preserve a reference unit while enabling parallel subsystem, communications, telemetry, sensor, and fault-injection work.

## MoonDAO request and return

The proposal requested $2,099.96 for hardware to support two ground testbeds. The proposed public return is a reproducible engineering package: BOM, assembly instructions, wiring diagrams, configuration records, software and configuration documentation, integration/test procedures, validation evidence, and a final technical report. A MoonDAO Town Hall or technical workshop was proposed for a community handoff in Q1 2027; its date and completion status are not yet recorded here.

## Roles and boundaries

- **SJSU student engineering program:** custodian of the physical FlatSat hardware and developer of student engineering contributions, subject to SJSU policies and permissions.
- **SDSI:** project coordination and repository stewardship for the MoonDAO public package.
- **MoonDAO community:** intended beneficiary of reusable documentation and released project software under the stated licenses.

These role descriptions do not replace a written agreement or change ownership of background intellectual property. Specific contributor ownership and release permission must be confirmed before publication.

## Status convention

Every project artifact should state one of: `planned`, `in work`, `tested`, or `accepted`. Include the date, configuration/revision, responsible reviewer, and evidence for a test or acceptance claim. Record deviations and limitations rather than presenting a template or a successful software run as engineering validation.
