# Public release boundary and provenance rules

This is a public repository for the MoonDAO FlatSat engineering package. Public visibility does not itself grant permission to publish every file available to the team.

## Include after review

- Project-specific BOMs, wiring diagrams, assembly/configuration instructions, software, test procedures, logs, validation evidence, and final report when authored by contributors with release authority.
- Project records needed to reproduce the released configuration, with revision, date, source, and license information.
- Links and citations to third-party materials when copying or redistribution is not authorized.

## Keep out until cleared

- NASA handbook or other third-party publications, vendor datasheets, and externally authored material unless their terms permit the planned redistribution.
- Internal CDR or spacecraft interface materials that are outside this MoonDAO FlatSat scope or whose owners have not approved publication.
- Student, university, donor, or staff personal information; credentials; unpublished results; confidential or NDA-covered data.
- Any item with uncertain authorship, ownership, license, export-control classification, or institutional approval.

The team has discussed an explicit culture of documenting responsibilities, authority, deliverables, decision rights, and significant commitments. Apply that principle here: resolve release authority with the relevant author and institution before a file is merged. Record the decision in the pull request or a project decision record. Do not assume that prior access or project participation equals publication permission.

## Before each public release

1. Review changed files and commit history for secrets and personal or restricted information.
2. Confirm contributor authority and applicable license for each new artifact.
3. Check all third-party notices and citations.
4. Confirm that claims of test completion are supported by traceable evidence.
5. Record the release tag, date, configuration baseline, and known limitations.
