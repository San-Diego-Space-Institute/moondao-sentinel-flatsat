## Objectives

1. Confirm each testbed matches the released configuration baseline.
2. Demonstrate power distribution, sensor/data paths, and applicable communications functions.
3. Compare the two units using the same procedure and controlled inputs.
4. Record faults, anomalies, and repeatability limits.
