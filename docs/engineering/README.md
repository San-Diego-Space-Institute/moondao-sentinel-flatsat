# Engineering deliverables

Populate this directory as the work is performed. The files below are starter templates, not evidence of completed work.

- `ASSEMBLY-CHECKLIST.md`: assembly and power-up sequence.
- `TEST-PLAN.md`: planned integration and comparison tests.
- `VALIDATION-REPORT-TEMPLATE.md`: evidence and results record.

Store released wiring diagrams and BOMs under `hardware/`. Put original project software under `software/`. Give each artifact a revision, date, author, configuration applicability, provenance, status, and license. Retain source data needed to reproduce reported results, subject to the publication boundary.
